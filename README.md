# LHC Open Data Analysis

## About me
I am a first-year physics student. This is my first data analysis
project, and I am doing it to learn the basics of Python data analysis
on real data from CERN's Open Data portal.

## My main goal
I want to gain experience in the kind of work I would do in the TDK,
and to prove that I am capable of it.

## About the project and how I work
The goal and the step-by-step plan of this project were designed by an
AI assistant (Claude). I carry out the steps, run the code, and try to
understand each part before moving on. I document my progress in small
steps with Git.

## The idea
The project analyses real collision data from CERN: it calculates the
invariant mass of decay products, plots it as a histogram, and fits the
resulting peak with a curve.

## Status
The project is in progress. The setup is complete.

## Setup
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Data files go into `data/` (not tracked by Git). Download instructions
will be added once I choose a dataset.
